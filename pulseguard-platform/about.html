TECHNICAL SPECIFICATIONS

Practical Engineering Features

Full architectural breakdown of the modular condition monitoring platform, sensor protocols, ISO 10816 vibration standards, and shift management.

01

Edge Sensor Telemetry

Continuous sub-second sampling via dual-core ESP32 microcontrollers. Reads digital temperature via Dallas 1-Wire bus (DS18B20), 6-DoF vibration acceleration via I2C (MPU6050), and AC/DC current draw via linear Hall-effect ADC (ACS712).

Hardware Node BOM: < ₹800 INR
02

Vibration Analysis (ISO 10816)

Calculates digital Root Mean Square (RMS) velocity and Peak Crest Factor. Automatically evaluates motor mechanical health against ISO 10816 severity bands (Zone A: Good, Zone B: Acceptable, Zone C: Warning, Zone D: Dangerous).

Industrial Standard Compliance
03

Incident Alerts & Thermal Relays

Automated contactor interlocks and thermal cooling fan triggers when temperatures or current loads exceed set limits. Includes manual override mode for calibrating plant setpoints and testing safety interlocks.

Automated Emergency Interlocks
04

Sensor Fault Isolation

Self-diagnostic impedance and communication heartbeat checks isolate sensor wiring disconnects from actual machine breakdown. Prevents unnecessary and costly motor shutdowns during minor wire faults.

No False Shutdown Trips
05

Shift Scheduling & Electricity (₹ INR)

Plant managers can configure machine shift timings, calculate electrical consumption in real-time in ₹ INR tariffs, and compute cumulative mechanical stress indices to schedule preventive thermal rest windows.

Wear-and-Tear Mitigation
06

1-Click PDF Audit Reports

Instant client-side PDF compilation using jsPDF. Exports a complete multi-device audit report featuring an executive fleet table, shift timings, historical readings, and an explicit abnormal activities log.

ISO Audit & Maintenance Logs
